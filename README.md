# 学习通自动刷课脚本 V4.1

> 本仓库 Fork 自 [chaolucky18/xuexitongScript](https://github.com/chaolucky18/xuexitongScript)，在原作者 V3 的基础上修复了视频卡住、"暂停-播放"反复拉扯等问题。

## 🚀 快速安装

**方式一：油猴一键安装（推荐）**

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击下面任一链接，在弹出的页面中点「安装」：
   - 👉 [安装链接（国内可用）](https://cdn.jsdelivr.net/gh/1668919739/xuexitongScript@master/v3_optimized.user.js)
   - 👉 [GitHub 备用链接](https://github.com/1668919739/xuexitongScript/raw/master/v3_optimized.user.js)
3. 打开学习通课程播放页（刷新一次），脚本会自动开始运行

> 新版 Chrome / Edge 如果装好后不运行：进入 `chrome://extensions`，打开右上角「开发者模式」，再在 Tampermonkey 的「详情」里打开「允许运行用户脚本」。

**方式二：控制台运行（不装扩展）**

1. 打开学习通课程播放页，按 `F12`，切到 `Console`（控制台）
2. 打开 [v3_optimized.js](v3_optimized.js)，点右上角复制按钮复制全部内容
3. 粘贴到控制台并回车

**常用命令**（在控制台输入）：`app.status()` 查看状态 · `app.stop()` 暂停 · `app.run()` 继续 · `app.nextUnit()` 跳到下一节

**倍速**：浮窗右上角齿轮设置里可选 1x / 1.25x / 1.5x / 2x（默认 2x），选择会被记住；课程限制倍速时自动按页面允许的速度播放。

**注意**：遇到视频内弹题、验证框时需要手动处理，处理完脚本会自动继续；课程页建议放在单独窗口，不要最小化。

**浮窗功能**：实时状态与章节、课程总进度和预计剩余时间、倍速选择、一键停止、设置（齿轮）、一键复制诊断信息、可拖动。需要你处理时会有提示音（可在设置里开启系统通知）。

**支持的任务点**：视频（自动播放、切下一节）· 课件 PPT/PDF（自动翻到底）· 点进即完成的资料页 · 直播回放（见下）。讨论、章节测验需要自己完成。

**直播回放**：点任务点里的「直播」卡片会打开新标签页（zhibo.chaoxing.com）。油猴版会在回放页自动运行；控制台方式需要在回放页再按 F12 粘贴一次同样的代码（浮窗会显示已观看时长和进度）；如果回放经常自己暂停，可在控制台左上角的「top」下拉框里选择 `live-rk.chaoxing.com` 开头的那一项，再粘贴一次，脚本就会直接控制播放器保持播放。回放按观看时长计算，请保持 1 倍速播放、不要最小化窗口，播完后约 5 分钟任务点更新。

---

当前版本以 `v3_optimized.js` 为唯一源码，油猴版由构建脚本生成。它聚焦于稳定播放与课程导航：

- 自动播放视频
- 视频结束后自动切换到下一小节
- 章节测验页面的受限跳转（最多尝试 3 次，防止循环）
- 从“学习目标”步骤自动切到“视频”步骤
- 手动点“2视频”页签或手动切换小节后自动重新接管播放
- 播放卡住时分级恢复（恢复播放 → 回退 1 秒 → 降倍速 → 重载视频 iframe）
- 页面暂停视频时事件驱动恢复，同一位置反复被暂停时停止拉扯并提示手动处理
- 识别视频内弹题，弹题期间不抢播放
- 同页多个视频逐个播放，跳过已完成任务点

这版的目标是保持原模板的行为方式，不再额外叠加复杂的后台保活、通知、测试按钮等附加层，尽量减少冲突。

## 当前脚本行为

### 1. 学习目标页

如果当前小节先进入的是“学习目标”而不是视频页，脚本会尝试点击顶部的 `2视频` / `视频` 标签进入视频步骤。

说明：
- 这条路径已经按当前页面结构收紧，只走顶部视频标签，不再点击底部 `下一节` 按钮
- 原因是底部按钮在当前页面里可能触发额外调试/暂停逻辑，稳定性较差

### 2. 视频页

进入视频页后，脚本会：

- 遍历所有可访问的 iframe 查找真实视频元素（单个跨域 iframe 不会影响其它 iframe 的查找）
- 每秒校验视频元素是否仍在页面上，iframe 刷新后自动重新查找
- 静音并调用 `play()`；页面暂停视频后 0.3 秒内恢复
- 区分“缓冲中”和“真卡死”：缓冲最多等待 20 秒且不回退进度，真卡死才逐级恢复
- 倍速只设置一次；若被页面改回，接受页面倍速，不再来回修改
- 10 秒内在同一位置被暂停 3 次时停止自动恢复，标签页标题显示【需处理】

常用配置（可在控制台修改 `app.configs.xxx`）：

```javascript
configs: {
    playbackRate: 2,            // 期望倍速
    fallbackRate: 1.0,          // 卡顿时的降级倍速
    stallMs: 8000,              // 非缓冲状态下多久无进度判定为卡住
    bufferingStallMs: 20000,    // 缓冲状态下多久无进度才处理
    maxReloadPerUnit: 3,        // 每个小节最多重载视频次数
    autoAdvanceNoVideo: false,  // 无视频小节是否自动跳过
    skipFinishedVideos: true,   // 跳过已完成任务点的视频
    guardFocus: true,           // 让各层页面认为窗口始终可见
    debugPause: false,          // 打印每次 pause() 的调用栈，用于排查
    showPanel: true,            // 左下角显示运行状态浮窗（点 – 收起，设为 false 隐藏）
}
```

### 3. 视频结束后

视频触发结束事件后，脚本会调用 `nextUnit()`，在课程目录树中定位到下一小节并点击进入。

### 4. 章节测验

如果当前不是视频而是“章节测验”页面，脚本会尝试点击：

```javascript
#prevNextFocusNext
```

以跳过当前测验步骤并继续后续流程。

### 5. 学习助手浮窗

- 状态框下方有「学习助手」总开关，打开后分「今天 / 课程 / 记录」三个标签页：今日目标进度环和本节笔记；课程进度、待手动完成清单和按章节整理的笔记（可一键复制）；学习时长统计、近 7 天柱状图和最近 12 周学习日历。
- 可在设置里开启休息提醒（连续学习 45 分钟提醒一次，默认关闭），完成今日目标、学完一章时给出小结；倍速、每日目标和各项开关在齿轮设置里。
- 笔记和学习记录只保存在本机浏览器，不上传任何地方。
- 后台播放：延时动作由后台线程计时，页面在后台也能按时恢复和切换。若仍被浏览器限速，把 chaoxing.com 加入「始终保持活动」的网站（Edge：设置 › 系统和性能 › 睡眠标签页；Chrome：设置 › 性能 › 内存节省程序），并且不要最小化窗口。
- 油猴版在学习通“课程”列表页也会显示浮窗：共几门课、已完成 / 进行中，以及一键“继续上次的课程”。

## 已知说明

### 0. 无视频或课件页面

默认不会自动跳过无法识别的无视频页面，避免在课件未完成时反复触发“当前章节还有任务未完成”的平台提示。控制台会给出明确日志；确认当前节点无需处理后，可手动执行 `app.nextUnit()`。

如果课程结构已确认安全，才可在控制台将 `app.configs.autoAdvanceNoVideo = true`，让脚本自动切换无视频小节。

### 1. 为什么有时会看到 `AbortError`

常见报错：

```text
The play() request was interrupted by a call to pause()
```

这通常不是视频坏了，而是：

- 页面从步骤页切到视频页时，播放器初始化会短暂停一下
- 页面内部脚本会在加载过程中重置播放状态
- 浏览器对媒体播放请求进行了短暂中断

脚本会优先尝试恢复播放，而不是立即判定失败。

### 2. 为什么会出现重复日志

如果同一页面反复粘贴执行脚本，会导致同一套监听和定时逻辑叠加，从而出现多次日志。

建议：

- 刷新页面后只执行一次
- 如果使用油猴版，尽量不要再在控制台重复粘贴执行

### 3. 为什么“静音播放成功”但一开始还能听到声音

旧逻辑里曾经会在静音启动成功后恢复声音。当前建议使用持续静音方式，不再自动恢复。

## 当前调试结论

目前这版已经验证：

- 顶部 `2视频` 标签可以程序化点击
- 手动进入视频页后可以自动播放
- 静音恢复链路可用

目前重点保留的是稳定性，不再继续叠加额外功能。
